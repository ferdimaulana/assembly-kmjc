Pengaturan Database Real-Time (Firebase Config)

Cara Menghubungkan Database Gratis Agar Sinkron di Semua Perangkat:
  1. Buka Firebase Console, buat Project baru.
  2. Pilih menu Build → Firestore Database, klik Create Database, pilih Start in test mode.
  3. Pilih menu Build → Authentication, aktifkan metode login Anonymous.
  4. Di halaman Project Overview, klik ikon Web (</>), lalu copy-paste bagian firebaseConfig ke kotak di bawah ini, atau masukkan langsung ke dalam file index.html sebelum di-upload ke GitHub.
